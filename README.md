# Japanese Learning Resource Management System

A C++ application for managing and searching
Japanese learning resources.

## Overview
A PBL2 project focused on OOP, data structures,
algorithms, and TXT-based data management.

## Technologies
- Language: C++17
- Storage: TXT files
- Interface: Terminal

## Main Features
- User authentication and authorization
- Learning resource management
- Searching, filtering and sorting
- Favorites and search history
